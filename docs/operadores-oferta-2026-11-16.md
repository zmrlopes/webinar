# Destinos identificados nos catálogos autorizados

Revisão de 16/11/2026, cruzada com a recolha de FAQs
`aa067bfa-132f-4029-9003-48163b87dd8e`, publicada a 12/11/2026.

Cada correspondência adicional em `src/lib/operadores-oferta.json` conserva o
destino, a categoria autorizada, uma fonte pública concreta, o nome do produto
e a data de consulta. O catálogo original e o histórico das FAQs ficam intactos.
Uma nova publicação de FAQs não recebe automaticamente este cruzamento; alterar
as regras de um operador também invalida as suas correspondências desta revisão.

Um país, continente ou referência genérica a safaris não comprova todas as suas
cidades ou países. As linhas de país com herança têm termos limitados para evitar
essa expansão. As correspondências não são disponibilidade em tempo real.

A ligação de controlo do computador estava indisponível nesta revisão. Não foi
feita uma nova pesquisa autenticada integral no motor iCliGo. Mantém-se a fonte da
pesquisa anterior de Hurghada/Nortravel e a confirmação pública posterior da sua
categoria Voos Especiais.

Validação: `npm run test:operadores`, `npm run typecheck` e `npm run build`.
